
----------------------------------------------------
   Замечания по использованию протокола X-Modem 
           для апгрейда модемов Courier
----------------------------------------------------


Для лучшей поддержки пользователей, работающих на платформе,
отличной от DOS, модемы Courier с FlashROM теперь можно
модернизировать, используя протокол X-Modem, который
присутствует в большинстве коммуникационных программ.  

Модемы с тукущей прошивкой датированной ранее 4/96 не поддерживают 
возможность модернизации, используя протокол X-Modem.
Такой модем следует сначала модернизировать через SDL.EXE (IDSDL_xx.EXE)
в DOS, установив прошивку датированую более поздней датой.

После установки такой прошивки включается команда AT~X!
Если с флэш памятью случится несчастье или вы "откатитесь" на 
более старую версию прошивки возможность использования X-Modem 
будет потеряна, а для восстановления опять придется прибегнуть 
к помощи SDL.EXE (IDSDL_xx.EXE).  Однако модемы, выпущенные фирмой
с прошивкой позже 4/96 не потеряют эту возможность даже в случаях,
описанных выше.
  IDSDLxxx.XMD - файл данных режима X-Modem (20.16Mhz по ATI7).
  ID25_xxx.XMD - файл данных режима X-Modem (25Mhz по ATI7).

(Это та же программа, что находится внутри SDL.EXE, но в другом
формате). Это файл, который вы посылаете модему в режиме
X-Modem. Файл, включенный в данную поставку, предназначается для
модемов Courier внутренних, внешних, PS/2.

Посылка новой версии прошивки с использованием X-Modem

1. Запустите коммуникационную программу, например, QuickLink II
или MacComCenter. Настройте ее таким образом, чтобы вы смогли
посылать команды AT и получать от модема ответ OK. Замечание:
Если вы посылаете файл с компьютера типа Macintosh,
удостоверьтесь, что вы делаете это НЕ используя формат
MacBinary. В MacComCenter например, выберите Setup -> File
Transfer и в параметрах MacBinary выберите "Never MacBinary".

2. Наберите AT~X! и нажмите Enter. Модем ответит следующим
образом:

AT~X!

SDL Xmodem file transfer - (Y)es (N)o (T)est

Выбор 'Y' приведет к запуску передачи файла; Выбор 'N' отменит
процесс и модем вернется к командному режиму.
 

Если вы ответите 'T' вы запустите режим перекачки файла в
защищенном тестировочном режиме. Этот режим проследит за
процессом передачи файла и за целостностью самого файла, не
стирая и не переписывая текущую прошивку.

3. Выберите 'T' для запуска тестировочной передачи файла, или
'Y' для реальной передачи и модернизации FlashROM.

SDL Xmodem file transfer - (Y)es (N)o (T)est >t 

* Test Mode - Flash ROM will not be modified* 
Begin Xmodem file transfer now.
CC

Модем начнет посылать символы 'C', которые используются как часть
"рукопожатия" (Hanshaking) протокола Xmodem. Сейчас вы можете начать
посылать IDSDLxxx.XMD ( ID25_xxx.XMD ) вашему модему использую
XMODEM-CRC или XMODEM-Checksum протоколы в вашей коммуникационной
программе.

4. После завершения передачи файла, модем выведет
заключительное сообщение.

AT~X!


SDL Xmodem file transfer - (Y)es (N)o (T)est >t 
Begin Xmodem file transfer now.  

CC

SDL Xmodem file transfer completed.

Calculating CRC... OK Resetting modem...OK


Если вы увидели сообщение OK, значит программная модернизация
завершена, и модем перезагрузится и вернется в командный режим.

5. Если модем по команде ATI7 выводит дату супервизора 2/25/97
или позже, введите следующую коммандную строку в вашей
терминальной программе, чтобы установить правильные заводские
установки по умолчанию:

AT&F1
AT+SF
ATS58=0S59=0S60=0S61=0S69=0&U0&N0
AT&W

----------------------------------------------------
                Аварийный загрузчик
----------------------------------------------------

Если флэш память откажется работать или модем не будет отвечать
на попытки загрузки Xmodem или SDL.EXE (IDSDL_xx.EXE), следуйте следующей
процедуре для активизации аварийного загрузчика flashROM.

1. Выключите питание вашего модема.

2. Установите переключатели DIP 1, 5, 10 в положение включено,
а 8 в значение выключено. (Для внутренних модемов: 1,5,10 -
включено, 7 - выключено.) Положение других переключателей
игнорируется.

3. Включите модем.

4. Запустите коммуникационную программу и пошлите прошивку,
используя протокол Xmodem или программу SDL.EXE (IDSDL_xx.EXE)
для ранних версий прошивки.

5. Выключите модем.

6. Установите переключатели DIP в исходное положение.

7. Включите модем.
