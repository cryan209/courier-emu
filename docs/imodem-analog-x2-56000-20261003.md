# Analog x2 56000 controls, 2026-10-03

56000 bps is not verified. The highest connection with intact bidirectional
messages, no guest NO CARRIER, and no CPU/DSP error remains
[53333 bps](../artifacts/imodem-analog-x2-53333-production-20261003/verification.json).
These controls do not establish a fundamental ceiling at 53333.

All five runs use the same NI1 profile, 20 ms exchanges, 600 million I-modem
instructions and 450 million analog instructions. The working configuration
starts with S54=0/S58=48 on both ends and analog &U26/&N39.
No carrier, rate, training decision or payload is injected.

The 56000 request's I-modem terminal reports 33333/x2 before losing carrier;
the analog terminal does not report CONNECT. The host's minimum request is
not an absolute enforcement mechanism: the original firmware also retains
its lowest fallback rate in the mask.

The beta-5 filter flattens the upper passband but reduces stopband rejection.
Its tone SNR is 57.77 dB at 3.8 kHz and 50.58 dB at 3.9 kHz, including
amplitude and phase error. It does not establish carrier.

3072 phases represent the fractions of the 8-kHz/9.6-kHz ratio exactly,
without increasing the FIR delay. The corresponding tone SNR improves from
61.90 to 80.92 dB at 3.8 kHz, while 3.9-kHz SNR remains 26.86 dB. The
connection rate nevertheless remains 53333 and the run reports analog
NO CARRIER, so the finer phases are not adopted.

Both filter experiments use separate native builds. Their patches are saved
with the artifacts. Their LIBRARY_SOURCES point at the diagnostic sources so
the loader cannot silently rebuild production sources into the alternate
library. Production code and the verified 53333 configuration are unchanged.
